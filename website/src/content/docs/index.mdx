## What is Actor Kit?

Actor Kit is a framework for building real-time, event-driven applications on Cloudflare Workers. Each actor is a Durable Object with a mailbox, private state, and behavior you define. One function — `actor()` — defines everything.

<CardGrid>
  <Card title="One API" icon="rocket">
    `actor()` defines state, roles, messages, views, timers, and side effects. No boilerplate.
  </Card>
  <Card title="Role-Based Access" icon="approve-check">
    Roles derived from state. Per-role messages and views. Authorization is structural.
  </Card>
  <Card title="Binary Sync" icon="seti:json">
    Schema-defined views with bitmask delta encoding. Only changed fields go over the wire.
  </Card>
  <Card title="Built for CF" icon="cloud">
    DO Alarms, SQLite persistence, WebSocket hibernation, actor-to-actor RPC. All native.
  </Card>
</CardGrid>

## Quick Example

```typescript
import { actor, message, view, schema, uint32, string } from "actor-kit";
import { z } from "zod";

const CounterView = schema({ count: uint32, lastUpdatedBy: string });

const increment = message(
  z.object({}),
  (state, _payload, { caller }) => ({
    ...state,
    count: state.count + 1,
    lastUpdatedBy: caller,
  }),
);

export const Counter = actor("counter", {
  input: z.object({}),
  init: () => ({ count: 0, lastUpdatedBy: null }),
  roles: { user: () => true },
  messages: { user: { INCREMENT: increment } },
  views: {
    user: view(CounterView, (state) => ({
      count: state.count,
      lastUpdatedBy: state.lastUpdatedBy ?? "",
    })),
  },
});
```
